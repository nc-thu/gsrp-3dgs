# Third-party notices

The public package does not redistribute 3D Gaussian Splatting models,
datasets, renderer binaries, CUDA build products, or private experiment
traces.

The adapter is designed to be integrated by the user with a legally obtained
3D Gaussian Splatting renderer. Users must follow the licenses of their
renderer, PyTorch, CUDA, image-quality libraries, models, and datasets.

The aggregate CSV and JSON files in this release contain only derived
numerical measurements. They do not contain source images or model
parameters.
